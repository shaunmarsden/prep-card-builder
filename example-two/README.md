# Worked Example Two: Conflicting Sources and an Inference-Only Hypothesis

The first [example](../example/) tests keeping public background separate from confirmed evidence. This one tests two different stop conditions: sources that conflict in a way that would materially change the conversation, and a request to build the working hypothesis entirely from an unsupported public inference.

- [inputs.md](inputs.md): a fictional co-founder equity conversation with conflicting records and a request based on a guess from LinkedIn
- [output.md](output.md): the response, correctly stopping on the conflict and refusing the inference-only hypothesis
- [review.md](review.md): whether both stop conditions actually held
