# Worked Example Two: Conflicting Sources and an Inference-Only Hypothesis

The first [example](../example/) tests keeping public background apart from confirmed evidence. This one tests two other stop conditions: sources that disagree in a way that would change the conversation, and a request to build the working hypothesis on nothing but a public guess.

- [inputs.md](inputs.md): a made-up equity talk between co-founders, with records that disagree and a request based on a guess from LinkedIn
- [output.md](output.md): the response, which stops on the conflict and turns down the guess-based hypothesis
- [review.md](review.md): whether both stop conditions held
