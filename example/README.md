# Worked Example

A made-up second-round interview. It tests whether the tool keeps public background (LinkedIn posts about a topic) apart from direct evidence of the skill the role needs.

- [inputs.md](inputs.md): who the interview is with, what it's for, and the sources available
- [output.md](output.md): the prep card [SKILL.md](../SKILL.md) produced
- [review.md](review.md): whether the card treated the LinkedIn posts as context rather than proof, and whether its questions aimed at the real gap

The repository doesn't record which model wrote this prep card, or whether it knew what the test was checking. Read it as an illustration of what a good run looks like, not as a logged run.
